# 🛡️ AL-AZRAQI v4.0

**إطار متقدم لاختبار أمان شبكات Wi-Fi – إصدار Shadow Interface**

أداة مبنية بلغة Python لمراقبة الشبكات اللاسلكية وتحليلها واختبار مستوى أمانها، مع واجهة Cyber HUD احترافية.

## 🚧 حالة المشروع (Project Status)

هذا المشروع عبارة عن نسخة تجريبية (Experimental Version)، تم تطويرها كتجربة أولية لاستكشاف إمكانيات بناء أدوات اختبار أمان الشبكات اللاسلكية.

الأداة لا تزال قيد التطوير، وسيتم العمل على تحسينها وإضافة المزيد من الميزات وتطوير الواجهة والأداء في الإصدارات القادمة.

**هذه ليست النسخة النهائية من المشروع، بل هي نقطة البداية نحو تطوير إصدار أكثر احترافية وتكاملًا.**

## 🚀 المميزات (Features)

- ✅ فحص الشبكات اللاسلكية (Scan Wireless Networks).
- ✅ إظهار أسماء الشبكات المخفية (Reveal Hidden SSIDs).
- ✅ مراقبة الحماية واكتشاف هجمات Deauthentication.
- ✅ تنفيذ اختبارات Deauthentication المصرّح بها.
- ✅ حفظ التقارير بصيغ JSON وCSV وTXT.
- ✅ واجهة احترافية بطابع الأمن السيبراني (Cyber HUD Interface).

## ⚙️ التثبيت (Installation)

### 1. استنساخ المشروع من GitHub

```bash
git clone https://github.com/MOHAB102/alazraqi.git
cd alazraqi
```

### 2. تثبيت المتطلبات

```bash
sudo bash install.sh
```

### 3. تشغيل الأداة

```bash
sudo python3 alazraqi.py
```

## 📦 المتطلبات

- **نظام التشغيل:** Kali Linux أو أي توزيعة Linux أخرى.
- **لغة البرمجة:** Python 3.8 أو أحدث.
- **كرت الشبكة اللاسلكي:** يجب أن يدعم وضع المراقبة (Monitor Mode) لاستخدام ميزات اختبار الشبكات اللاسلكية التي تتطلب ذلك.

## ⚠️ إخلاء المسؤولية

تم تطوير هذه الأداة للأغراض التعليمية والبحثية في مجال الأمن السيبراني المصرّح به فقط.

يُرجى استخدامها فقط على الشبكات اللاسلكية التي تملكها أو لديك إذن صريح من مالكها لاختبارها.

المطوّر غير مسؤول عن أي إساءة استخدام أو أنشطة غير قانونية أو غير مصرّح بها.
